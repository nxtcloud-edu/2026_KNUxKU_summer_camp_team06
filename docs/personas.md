# 테스트 페르소나 — 수집 데이터 기반

> OWNER: B (신민서). `data/opportunities.json` 수집 데이터의 실제 자격조건 분포에 맞춰
> 설계한 프로필이다. C(엄세연)의 `eligibility_agent.py` 판정 로직을 테스트할 때
> 이 페르소나 x 공고 조합을 그대로 쓸 수 있다.
>
> **R7 준수**: 출생연도·지역(시/군/구)·상태·소득구간·관심사만 사용. 실명/주민번호/상세주소
> 없음 — 전부 테스트용 가상 인물이다.
> **주의**: 아래 `status` 필드는 자유 서술형이다. 실제 온보딩 스키마(enum 등)는 A가
> `src/models.py`에서 확정한다. 이 문서는 그 전까지 C가 판정 로직을 미리 테스트하기
> 위한 참고 자료다.

## 온보딩 필드 (Project.md 기준)

```
UserProfile (안):
  birth_year: int
  region: str          # 시/군/구 단위까지만 (R7)
  status: str          # 재학/휴학/졸업/졸업예정/미취업/재직 등 자유 서술
  income_bracket: Optional[str]   # 예: "중위소득 100% 이하" (선택 입력)
  interest: str        # 관심사 한 줄
```

## 커버리지 메모 (실제 20건 정규화 결과 기준)

| 조건 타입 | 실제 등장 횟수 | 테스트 담당 페르소나 |
|---|---|---|
| age | 14 | 김서연(24, 통과) / 박준영(27, 아시아프 미달) / 최민재(31, 상한초과) |
| region | 4 | 정다인(강원·서울 지역조건 탈락) |
| status | 16 | 박준영(대학원생 제외) / 이하늘(졸업생 제외) |
| income | 3 | 정다인(소득구간 애매성 — unknown 처리) |
| duplicate | 3 | 최민재(다른 대외활동) / `opp-grant-02,03`(기수혜자·중복참여 제한) |
| military | 5 | 최민재(입영예정 → 카카오창작재단 탈락) / `opp-grant-02,03`(병역 관련 연령 연장) |
| period | 16 | 전 페르소나 공통 (마감 역산 로직 D에서 사용) |
| etc | 4 | 정다인(사업자등록 여부) / `opp-grant-06` |

`scripts/run_pipeline.py`로 20건 전체를 실행한 결과 19건이 `ok`, 1건(`opp-bootcamp-01`)은
공고 원문 자체에 "학력과 전공은 중요하지 않습니다"라고 명시돼 있어 조건이 없는 게 정상 —
`partial`로 정확히 표시된다(R3 그대로 동작).

**알려진 한계**: `opp-grant-04`(경기도 청년기본소득)의 "24세 청년(2001. 4. 2. ~ 2002. 4. 1.
출생자)" 같은 표현은 정규식이 나이 조건으로 잡지 못하고 생년월일 기간(period)으로만 잡는다.
이런 표현 다양성 문제는 정규식만으로는 한계가 있고, AWS 연동 후 실제 LLM 추출로 교체하면
개선된다 (mock의 의도된 한계 — `_verify_grounding()` 근거 검증은 그대로 유지됨).
